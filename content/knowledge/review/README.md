# Paquetes de revisión de contenido

Estos archivos contienen páginas y addenda preparados para revisión de Sonia McRorey.

Flujo obligatorio:

1. Tina from Marketina prepara el borrador usando fuentes verificadas de Sonia.
2. Se revisan fuentes, intención, enlaces, metadatos y límites de contenido.
3. Sonia aprueba o solicita cambios.
4. Solo después de la aprobación se promueve el contenido al generador estático y se publica la versión `.md` en Cloudflare.

Los archivos de esta carpeta no son todavía contenido público ni instrucciones para que un modelo invente respuestas.
