# Sonia Knowledge Card Pipeline

Purpose: build a Sonia-only Spanish Q&A corpus for AI retrieval, Cloudflare grounding and search-answer readiness.

## Folders

- `queue/`: candidate cards generated by the daily agent but not approved.
- `approved/`: source-of-truth cards included in the public Knowledge API during build.
- `rejected/`: rejected cards kept for audit and duplicate prevention.
- `reports/`: daily generation, validation and source-coverage reports.

## Daily Batch Rules

- Target: 75 approved cards per day after validation.
- Generate more candidates than needed, then reject weak or duplicate cards.
- Every approved card must include `id`, `ontologyNode`, `userIntent`, `question`, `shortAnswer`, `routePriority`, `anchorPhrases`, `evidenceTopics`, `conversionBridge` and `guardrails`.
- Answers must be Spanish-first, concise and grounded in Sonia McRorey source material.
- No external company or unrelated project content.
- No invented prices, guarantees, credentials, agenda, email routing status or medical/therapy claims.
- GEO cards must avoid doorway duplication; each market needs local wording, service context and relevant route mapping.

## Public Outputs

Build publishes:

- `/api/knowledge/questions.json`
- `/api/knowledge/questions.md`
- `/api/knowledge/cards/index.json`
- `/api/knowledge/cards/{layer}.json`
- `/api/knowledge/internal-link-mesh.json`
